## 🐛 Troubleshooting

### If Login Fails
- Check Render logs for database initialization
- Owner accounts should be auto-created
- If needed, manually run: `python backend/create_unified_owners.py`

### If Terminal Doesn't Show
- Hard refresh the page (Ctrl+Shift+R)
- Check browser console for errors
- Verify API calls are going to `/api/v1/*`

### If Scans Show 0 Vulnerabilities
- Backend might be cold-starting (first request takes longer)
- Check Render logs for pentest brain execution
- Try a different target URL
